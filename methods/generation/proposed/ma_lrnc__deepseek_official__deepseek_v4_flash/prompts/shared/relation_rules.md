# 学术逻辑关系共同规则

## 关系成立门槛

只有以下四项同时满足时，才判定两篇论文存在实质性学术逻辑关系：

1. 双方存在具体、可对齐的知识对象，例如理论命题、概念框架、方法模型、
   变量关系、具体结论或适用边界。
2. 能够明确命名承接、拓展、印证、修正、挑战或严格互补之一，而不是笼统
   声称两篇论文相关。
3. 双方原文证据能够由关系解释桥接，共同支持关系类型和方向。
4. 能够排除题名、主题、术语、对象、常见方法或结论表面相似等替代解释，并且
   不存在明确的时间方向矛盾。

任一门槛不满足时，在输入完整的前提下输出无关系记录。直接引用既不是关系
成立的必要条件，也不是充分条件。本任务识别知识内容上的逻辑关系，不推断
作者阅读、受启发、有意继承或其他历史影响。

## 关系类型与排除条件

- **承接**：一篇论文沿用、采用或复用另一篇论文的具体理论、方法、模型或
  指标，没有形成实质改变。出现实质新增或改造时判为拓展。
- **拓展**：一篇论文在另一篇论文的具体知识对象上增加变量、机制、方法、
  范围、对象或应用情境。只是原样采用时判为承接。
- **印证**：一篇论文通过新的数据、样本或方法，为另一篇论文的具体观点或
  发现提供独立且可比较的一致证据。结论表面相似不足以成立。
- **修正**：一篇论文保留另一篇论文的基本方向，但调整其条件、边界、程度或
  部分解释。否定核心观点时判为挑战。
- **挑战**：一篇论文对另一篇论文的核心观点、方法有效性或主要结论提出实质
  质疑、否定或竞争性解释。只补充适用边界时判为修正。
- **互补**：两篇论文从不同、不可替代但可以结合的方面共同解释同一问题，
  交换 A/B 后关系仍成立。存在明确单向知识动作时不得判为互补。

## 主要关系选择

同一论文对出现多个知识动作时，不按固定的全局关系等级选择。应选择与动作
论文的核心研究目标、主要理论或模型、核心研究设计和主要发现最相关，并且
最能解释双方核心知识变化的动作。必要时再比较证据直接程度和对主要差异的
解释覆盖。

使用以下局部裁决规则：

- 同一对象上既有原样采用又有实质新增，且新增是核心变化时，判为拓展。
- 总体支持另一篇论文但核心贡献是调整适用条件时，判为修正而非印证。
- 沿用部分框架但否定核心观点时，判为挑战。
- 存在明确单向知识动作时，不判为互补。
- 把另一篇论文的方法作为工具，但没有检验其具体观点或发现时，不判为印证。

## 方向

方向表示“实施学术动作的论文 → 该动作所针对的论文”：

- `a_to_b`：论文 A 对论文 B 实施承接、拓展、印证、修正或挑战。
- `b_to_a`：论文 B 对论文 A 实施上述动作。
- 承接、拓展、印证、修正和挑战不得使用 `symmetric`。
- 互补必须使用 `symmetric`。

A/B 是按论文 ID 固定的输入与存储坐标，不代表发表先后或关系方向。发表日期
只用于排除时间上不可能的方向，不能单独证明关系存在。
