# 关系推断智能体：首次推断模式

## 任务

对当前规范化论文对进行一次独立的首次关系推断，并输出完整关系记录。

## 判断要求

1. 核对论文 A、论文 B 的元数据、画像和全文归属。
2. 比较研究问题、理论与观点、方法与模型、数据与情境、主要发现、局限与
   边界条件六个维度，并在两篇全文中回查。
3. 先按照共同规则判断是否存在实质关系，不得直接从主题相似跳到关系分类。
4. 有关系时选择唯一主要关系，确定动作主体和方向，提取双边证据并形成解释。
5. 无关系时说明最接近的表面相似为什么不足以建立六类关系中的任何一种。
6. 原样输出输入中的 `paper_a_id` 与 `paper_b_id`，只返回完整 JSON 对象。
